# BLOCK EMPIRE · The Syndicate — גרסה 0.14

חבילת קוד המקור של הגרסה שפורסמה ב־18.10.2026, עם מפעיל מקומי נוסף ל־Windows, macOS ו־Linux.

## הפעלה מהירה ב־Windows

1. חלצו את כל קובץ ה־ZIP לתיקייה במחשב. אין להפעיל מתוך חלון ה־ZIP.
2. התקינו Node.js בגרסה 24 ומעלה אם הוא אינו מותקן. אתר ההתקנה הרשמי: https://nodejs.org
3. לחצו פעמיים על `START-GAME.bat`. המשחק ייפתח בדפדפן.
4. השאירו את חלון ההפעלה פתוח בזמן המשחק. לסיום לחצו Ctrl+C בחלון.

אין צורך ב־npm install להפעלה המקומית. אין לפתוח את index.html ישירות: המשחק משתמש במודולים ובשרת מקומי.

אפשר גם לפתוח את התיקייה ב־VS Code ולהריץ בטרמינל:

```bash
node start-local.mjs
```

פתחו את הכתובת המוצגת, בדרך כלל http://localhost:5173/play/index.html

אם פורט 5173 תפוס:

```bash
node start-local.mjs --port 5174
```

ב־macOS וב־Linux מפעילים באותו אופן דרך הטרמינל. אפשר גם להשתמש ב־`npm start` ללא התקנת חבילות.

## משחק עם חברים

**באינטרנט:** הגרסה המפורסמת כבר זמינה כאן: https://block-empire-pavel.pashkin18.chatgpt.site
אפשר לפתוח אותה גם מקובץ `OPEN-ONLINE.url`, וליצור חדר וקישור הזמנה מתוך המשחק.

**ברשת הביתית:** הפעילו את השרת כך:

```bash
node start-local.mjs --host 0.0.0.0 --port 5173
```

מצאו את כתובת ה־IPv4 של המחשב ברשת הביתית, למשל בעזרת `ipconfig` ב־Windows. במכשירים המחוברים לאותה רשת פתחו `http://כתובת-המחשב:5173/play/index.html`. אם Windows מבקש לאפשר גישה, בחרו ברשת הפרטית שלכם. צרו את החדר דרך כתובת הרשת הזו ושלחו את הקישור שנוצר. כתובת localhost מיועדת למחשב המקומי בלבד.

השרת המקומי כולל את מנגנון החדרים של המשחק ושומר אותם ב־SQLite. הוא אינו מתפרסם אוטומטית באינטרנט; לציבור משתמשים באתר שכבר פורסם או מקימים אחסון נפרד.

## משחק בטלפון והתקנה למסך הבית

הממשק מותאם למסכים צרים ולמגע, בלי להחליף את פריסת המחשב. במפה אפשר לגרור באצבע אחת ולהגדיל או להקטין בצביטה בשתי אצבעות; כפתורי הזום זמינים גם הם. חלונות המשחק נגללים גם במסכים קצרים ובמצב אופקי.

למשחק בטלפון באותה רשת ביתית השתמשו בהוראות הרשת למעלה. השרת במחשב חייב להישאר פועל. אין צורך להתקין Node.js בטלפון, ואין אפשרות להפעיל את חבילת המקור ישירות מתוך תיקיית ההורדות בטלפון.

להתקנה כיישום יש לפרסם את הקבצים המעודכנים באתר עם HTTPS. באנדרואיד בחרו בתפריט הדפדפן בהתקנת היישום או בהוספה למסך הבית; באייפון פתחו ב־Safari ובחרו שיתוף ואז הוספה למסך הבית. ההתקנה אינה קובץ APK ואינה דורשת חנות אפליקציות. קובצי ההתקנה כלולים בחבילה, אך האתר הציבורי הקיים אינו מתעדכן אוטומטית משינויים מקומיים.

לאחר טעינה ראשונה מלאה מכתובת מאובטחת, קובצי המשחק נשמרים לשימוש ללא רשת. משחק יחיד ושמירות מקומיות זמינים באותו מכשיר; חדרים עם חברים דורשים חיבור לשרת. תמיכת התקנה ושימוש ללא רשת דורשת HTTPS, למעט localhost במחשב; כתובת HTTP של הרשת הביתית מיועדת למשחק מחובר בלבד. שמירות אינן מסתנכרנות בין המחשב לטלפון.

## מה נכלל במשחק

- מכרזים, הצעות רכישה, פשיטות, ריגול, אבטחה ותיקונים.

זהו משחק דפדפן עם גרפיקת Canvas ו־SVG. החבילה אינה פרויקט Unreal ואינה קובץ APK/EXE. הכסף, המניות והמטבעות הם רכיבי משחק בלבד.

## שמירות

משחק יחיד נשמר בדפדפן עבור הכתובת שבה משחקים. חדרים מקומיים נשמרים בתיקייה `.local-data` שנוצרת בהפעלה הראשונה. להשבתת השרת אין צורך למחוק אותה. שמירות מהאתר הציבורי אינן מועתקות אוטומטית למחשב המקומי; מעבר בין כתובות או פורטים יוצר סביבת שמירה נפרדת בדפדפן.

## עריכת הקוד

פתחו את התיקייה ב־VS Code. רוב השינויים במשחק נמצאים ב־`public/play`. לאחר עריכה רעננו את הדפדפן. אפשר להשתמש ב־`npm run dev:game` להפעלה עם טעינה מחדש של השרת בעת שינויי קוד.

הפעלת אתר Vinext המלא היא מסלול פיתוח נפרד ודורשת התקנת התלויות באמצעות pnpm. המפעיל המקומי הוא המסלול המוכן להפעלה בחבילה הזו; הוא משתמש ב־SQLite במקום סביבת האירוח הציבורית. אין צורך לשנות או לפרסם מחדש את האתר כדי לשחק מקומית.

## פרסום הגרסה המעודכנת ב־Cloudflare

הגדרות הפרסום נמצאות ב־`wrangler.jsonc`. הן מפרסמות את המשחק ואת שרת החדרים, ללא צורך בבניית מעטפת React או בהתקנת כל חבילות הפרויקט.

```bash
npx --yes wrangler@4.92.0 login
npx --yes wrangler@4.92.0 d1 create block-empire
```

לפני פרסום ראשון החליפו את מזהה הדוגמה בשדה `database_id` במזהה מסד הנתונים שהפקודה החזירה. לאחר מכן:

```bash
npx --yes wrangler@4.92.0 d1 migrations apply block-empire --remote
npx --yes wrangler@4.92.0 deploy
```

פקודת הפרסום מחזירה כתובת HTTPS ציבורית ב־`workers.dev`. הכתובת הישנה ב־`chatgpt.site` אינה מתעדכנת מכך. שמירות מקומיות ונתוני חדרים מהמחשב אינם מועלים; באתר החדש נוצר מסד חדרים נפרד. עד שההתחברות, יצירת מסד הנתונים והפרסום מצליחים, הגרסה המעודכנת אינה באוויר.
